# Olaf Zen

Your own wallpaper on every screen: one picture across all your monitors, or one per
display. It also works on a Mac where the company locks the wallpaper.

**Download and install: [olafzen.com](https://olafzen.com)**

This repository holds only the downloads ([Releases](https://github.com/teamolaf/olafzen/releases)).
The newest one is always on olafzen.com, with the install steps.

- Free, no account, no network use.
- macOS 13 or later, Apple silicon and Intel.
- Questions: hello@olafzen.com
